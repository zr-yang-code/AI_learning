今天首先弄清楚了几个经常看到，但容易混淆的概念。

### AI —— 一个大的目标

AI（Artificial Intelligence）是一个比较大的概念。

简单来说：

> **AI 的目标，是让机器表现出类似“智能”的能力。**

例如：

* 识别图片
* 理解语言
* 进行推理
* 下棋
* 自动驾驶
* 生成文字、图片、代码

### Machine Learning（机器学习）—— 实现 AI 的一种重要方法

传统程序通常是：

```text
规则 + 数据
   ↓
程序
   ↓
结果
```

机器学习则更像：

```text
数据 + 正确答案
      ↓

      ↓
    模型
      ↓
    预测
```

也就是说：

> **不是人把所有规则都写出来，而是让机器从数据中学习规律。**
**也就是说人工提供数据集给机器进行学习**

### Deep Learning —— 机器学习的一种方法

深度学习是机器学习中的一个重要分支。

它主要使用：

> **多层神经网络来学习复杂的数据规律。**

所谓“深度”，主要可以理解成神经网络具有很多层。

今天对深度学习的理解，从“定义”进一步深入到了“它是怎么工作的”。

可以先用一句话概括：

> **深度学习，就是利用多层神经网络，通过大量数据训练，让模型自动学习数据中的复杂规律。**
**神经网络也分为很多种不同的类型：全连接神经网络（MLP）、卷积神经网络（CNN）、循环神经网络（RNN）等。这个等待日后学习。**
例如：

```text
原始图片
   ↓
```

# 03. 神经网络是怎么“学习”的？

这是今天最重要的部分。

一个神经网络里面存在大量的**参数（Parameters）**。

例如：

```text
输入 x
  ↓
  w₁
  ↓
神经元
  ↓
  w₂
  ↓
输出 y
```

这里的：

```text
w₁
w₂
...
```

就是模型中的参数。

训练神经网络，本质上就是：

> **不断调整这些参数，让模型的预测结果越来越准确。**

**并且会根据实际值和预测值之间的误差也就是LOSS再根据梯度来判断参数应该往哪个方向调整，并通过优化器（也就是利用一些算法）来更新参数。**

---

# 04. Loss：模型怎么知道自己“错了多少”？

假设：

```text
真实答案 = 10
模型预测 = 6
```

显然模型预测错了。

我们需要一个东西来衡量：

> **模型到底错了多少？**

这就是：

## Loss（损失函数）

例如最简单的平方误差：

```text
Loss = (预测值 - 真实值)²
```

那么：

```text
Loss = (6 - 10)²
     = 16
```

所以：

```text
Loss 越大
↓
预测结果通常越差

Loss 越小
↓
预测结果通常越接近目标
```

因此可以把 Loss 理解成：

> **给模型这一次预测打一个“分数”。**

---

# 05. 但是有一个问题：知道 Loss 之后，参数应该怎么改？

这是今天学习过程中非常关键的一个问题。

例如：

```text
当前参数：

w = 3

预测：

y = w × x

x = 2

所以：

y = 3 × 2 = 6
```

目标是：

```text
10
```

Loss：

```text
16
```

现在模型知道自己错了。

但是：

> **Loss = 16 并不能直接告诉模型 w 应该变成多少。**

究竟应该：

```text
w = 3.1 ?
w = 4 ?
w = 5 ?
w = 100 ?
```

这时候就需要：

# Gradient —— 梯度

---

# 06. 梯度到底是什么？

梯度可以简单理解成：

> **Loss 对某个参数的变化有多敏感，以及参数应该往哪个方向调整。**

数学上，例如：

```text
∂Loss / ∂w
```

表示：

> 当 `w` 发生变化时，Loss 会怎么变化。

例如：

```text
∂Loss / ∂w = -16
```

这个结果告诉我们：

> 当前情况下，如果想让 Loss 下降，参数 `w` 应该向增加的方向调整。

所以可以形成一个非常重要的认识：

```text
Loss
 ↓
告诉我们“错多少”

Gradient
 ↓
告诉我们“应该往哪个方向改”
```

---

# 07. 为什么叫“梯度下降”？

可以把 Loss 想象成一座山。

```text
Loss
 ↑
 │          ●
 │        ／
 │      ／
 │    ／
 │  ●
 │／
 └────────────────→ 参数
```

我们希望：

```text
Loss ↓
```

也就是从山上走到更低的位置。

梯度可以理解成：

> **告诉我们当前这个位置，哪个方向是“上坡”最陡的方向。**

而我们想下山，所以要：

```text
沿着梯度的反方向走
```

这就是：

# Gradient Descent（梯度下降）

---

# 08. 优化器是什么？

今天还理解了一个重要概念：

> **Optimizer（优化器）本质上就是一套用于更新模型参数的算法。**

最简单的优化器就是：

```text
Gradient Descent
```

它的核心思想：

```text
新的参数
=
旧的参数
-
学习率 × 梯度
```

写成公式：

```text
w_new = w_old - η × gradient
```

其中：

* `w`：参数
* `gradient`：梯度
* `η`：学习率（Learning Rate）

---

# 09. 一个完整的小例子

假设：

```text
x = 2
目标值 = 10
w = 3
```

模型：

```text
y = w × x
```

所以：

```text
y = 3 × 2
  = 6
```

计算 Loss：

```text
Loss = (6 - 10)²
     = 16
```

然后通过反向传播计算：

```text
∂Loss / ∂w = -16
```

假设：

```text
learning rate = 0.1
```

使用梯度下降：

```text
w_new
= 3 - 0.1 × (-16)
= 4.6
```

新的预测：

```text
y = 4.6 × 2
  = 9.2
```

可以看到：

```text
第一次：

预测 = 6
Loss 较大

      ↓

更新参数

      ↓

第二次：

预测 = 9.2
Loss 变小

      ↓

继续更新

      ↓

预测逐渐接近 10
```

这就是神经网络训练的基本思想。

# 10. 反向传播到底干什么？

今天进一步了解到：

> **反向传播（Backpropagation）的核心作用，就是计算梯度。**

假设一个神经网络：

```text
x
↓
w₁
↓
h
↓
w₂
↓
y
↓
Loss
```

我们最终计算出了：

```text
Loss
```

现在我们需要知道：

```text
w₁ 对 Loss 有多大影响？
w₂ 对 Loss 有多大影响？
```

于是从 Loss 开始反方向计算：

```text
Loss
 ↑
 y
 ↑
 w₂
 ↑
 h
 ↑
 w₁
```

通过**链式法则（Chain Rule）**，计算每一个参数对应的梯度。

例如：

```text
∂Loss/∂w₁
=
∂Loss/∂y
×
∂y/∂h
×
∂h/∂w₁
```

所以：

> **反向传播并不是直接修改参数，而是在计算“每个参数应该怎么改”的依据——梯度。**

# 11. 到这里，终于可以理解“机器自己学习”是什么意思了

今天最大的收获之一：

所谓：

> “机器自己学习”

并不是机器像人一样思考。

而是训练程序在不断执行：

```text
        ┌──────────────┐
        │    输入数据   │
        └──────┬───────┘
               ↓
        ┌──────────────┐
        │   神经网络    │
        └──────┬───────┘
               ↓
        ┌──────────────┐
        │   预测结果    │
        └──────┬───────┘
               ↓
        ┌──────────────┐
        │     Loss     │
        └──────┬───────┘
               ↓
        ┌──────────────┐
        │   反向传播    │
        └──────┬───────┘
               ↓
        ┌──────────────┐
        │     梯度      │
        └──────┬───────┘
               ↓
        ┌──────────────┐
        │    优化器     │
        └──────┬───────┘
               ↓
        ┌──────────────┐
        │   更新参数    │
        └──────┬───────┘
               │
               └──────────→ 重复训练
```

也就是说：

> **模型通过不断计算 Loss → 梯度 → 更新参数，让自己的预测结果逐渐变好。**
